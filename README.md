# 📦 Delivery Management System - Modern Pigeon

A full-stack Delivery Management System with multi-view support, real-time tracking, and chat, built using modern web technologies.

## 🚀 Features

- 📦 Package quoting & tracking
- 👥 Multi-view interface (for customers, couriers, admins)
- 💬 Chatbot powered by Dialogflow + NLP
- 🔥 Real-time backend using Firebase
- 🌐 Scalable cloud services via GCP

## 🧰 Tech Stack

- **Frontend**: React JS  
- **Backend**: Node.js  
- **Database & Auth**: Firebase  
- **Cloud**: Google Cloud Platform (GCP)  
- **Chatbot**: Dialogflow + NLP (in progress)

## 🛠 Getting Started

```bash
git clone https://github.com/AAZINSHAIKH/delivery_management_system.git
cd modern-pigeon
npm install
npm start
```

Then visit [http://localhost:3000](http://localhost:3000)
